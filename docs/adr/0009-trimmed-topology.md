# ADR 0009：裁剪拓扑语义 v1

状态：已采纳（2026-10-13）；关联 GS-007。此记录确定后续实现契约，不表示 p-curve、接缝和拆边已经实现。

## 决定

- 承载曲线的固有 ParamRange 与拓扑边的实际区间分开。边区间使用有限、有序的展开参数，周期曲线的跨周期圆弧保留超过一个周期端点的数值，不能先 normalize 两端而丢失路径。完整圆边明确表示一整周期，不能把相同归一化端点解释为空边。
- fin 参数方向由 Sense 决定，负向 fin 从边区间末端到起点。二维参数曲线属于一次 fin 使用，而非共享三维 edge；同一接缝边在同一面上的两次使用必须能够记录不同周期分支。
- p-curve 的参数到三维曲线参数映射必须显式记录并可验证。初版只支持经验证的仿射映射；无法确定的映射返回 Unimplemented，不伪造二维边界。
- 内外环角色独立于几何中心、数组顺序和单独一条 fin 的 Sense。环角色及参数信息先通过 Model 的附属表表达，以保持既有实体布局、原始编辑接口和受保护检查器测试的源码兼容。
- 参数元数据随实体创建、修改、删除参加同一事务。附属表不能有悬空 ID，查询不能把缺失数据当作默认正确数据。
- 后续编辑接口至少包括参数查询、裁剪赋值、fin 使用映射、接缝分支、拆边及环重建；GS-009 的实现必须覆盖跨周期、负向 fin、同边两次使用及几何一致性。

## 验证边界

现有检查器只能验证既有拓扑与部分几何，新增参数验证放在独立测试和明确诊断中。受保护检查器/验证设施的规则扩展由其维护者完成，不在本轮修改。事务先覆盖现有存储；新增附属表落地时必须纳入快照和失败测试。
