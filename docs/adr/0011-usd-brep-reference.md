# ADR 0011：增加 USD BRep / SMLib 代码参考

状态：已采纳（2026-10-14）。补充 ADR 0007；不改变其对 OCCT、truck 和商业内核的来源约束。

## 背景

用户新增参考目录 `D:\CAD\liuxin\NURBS`。实际仓库为其下的 `usd-brep`，origin 指向 `NVIDIA-Omniverse/usd-brep`，本地 HEAD 为 `c9c5979f04cea8c38213004d4f04df0dcfb40d05`（Release 1.0.0）。该仓库包含 SMLib 的 C++ 几何、拓扑和建模算法实现，可补充 Gensolid 当前的 GS-009、GS-010、GS-012、GS-015、GS-016/017 及阶段 I 参考。

## 决定

- 将该版本列为可读源码参考。优先分析裁剪边/edgeuse、周期区间、NURBS 插结/拆分及局部与全局求解分层；Gensolid 保留 Rust、现有精度模型、事务、类型化 ID、解析 B-rep 与验证器优先的路线。
- 经逐文件核对为 Apache-2.0、来源清晰的算法，可按模块选择性改写或移植。移植前记录上游仓库、固定提交、相对路径、文件哈希、原版权和许可证；标明修改，并在 NOTICE 保留适用归属。未实际移植时不将代码写成已采用。
- 根许可证不代替文件及依赖审查。OpenUSD、提案文件、GUI 和 OCCT 适配器分别核对其条件；含额外来源疑点的数值例程先按公开数学资料独立实现。本次不增加 Gensolid 依赖、不接入 SMLib C++ 动态库。
- 不沿用上游固定容差、裸浮点拓扑判断、断言退出、指针所有权或失败后报成功的契约。候选算法必须适配 Precision、显式错误、事务及既有检查规则。
- SMLib 若用于独立对拍，须先完成其构建和自身检查，记录单位、误差和已知问题，并与解析基准/其他独立结果交叉验证。本次静态审阅不视为运行验收。
- 上游的 runtime edgeuse 与 staging edgeuse 方向约定须区分，不能直接套用到 Gensolid fin。初版仍遵循 ADR 0009；若需改变 Gensolid 参数契约，另立 ADR。

## 后果

参考范围扩展，现有 29 个 GS 工作项及 RA-001 目标保持不变。优先为 GS-009 提供设计和反例输入，不提前宣称通用求交、布尔、圆角或交换完成。具体入口、限制和采用顺序见[中文评估](../nurbs-reference-assessment.zh-CN.md)。

本批仅新增参考与评估，没有复制上游算法到内核，也没有修改受保护检查层。
